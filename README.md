# Habit-Tracker — Your Daily OS

A personal productivity dashboard built around a real fixed schedule (classes, a genuine
2-hour study block, lunch, dinner), with a to-do list, day routine, health & calorie tracker,
habit streaks, focus timer, goals, business tracker, and journal.

- `index.html` — landing / download page
- `app.html` — the actual app (single self-contained file, runs entirely in the browser,
  saves your data locally via `localStorage`, no backend, no login)

## Run it locally
Just double-click `app.html`, or `index.html` to see the landing page first.

## Host it live (GitHub Pages)
1. Push this repo to GitHub (see commands below).
2. On GitHub: **Settings → Pages → Source → Deploy from a branch → `main` / `root`** → Save.
3. Your live link will be:
   `https://<your-username>.github.io/habit-tracker/`
   (the app itself will be at `.../app.html`)

GitHub Pages usually takes 1–2 minutes to go live after the first push.
